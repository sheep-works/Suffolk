================================================================================
 Suffolk - Crates 概要（アーキテクチャと依存関係）
================================================================================

Suffolk は Rust の「ワークスペース（Workspace）」機能を用いて、
責務ごとに 5 つのクレート（ライブラリ、バイナリ、WASMバインディング）に分割されています。

【アーキテクチャの階層構造】

        ┌──────────────────────────────┐        ┌──────────────────────────────┐
        │         suffolk-cli          │        │         suffolk-wasm         │
        │      (CLI コマンド本体)      │        │   (Web / VS Code WASM API)   │
        └───────┬──────────────┬───────┘        └───────┬──────────────┬───────┘
                │              │                        │              │
                ▼              ▼                        ▼              ▼
        ┌──────────────────┐   │               ┌──────────────────┐    │
        │ suffolk-formats  │───┼──────────────▶│  suffolk-codec   │◀───┘
        │ (Word, Excel等)  │   │               │ (XLIFF, JSON等)  │
        └────────┬─────────┘   │               └────────┬─────────┘
                 │             │                        │
                 └─────────────┼────────┬───────────────┘
                               │        ▼
                               │┌──────────────────┐
                               └│    suffolk-ir    │  (共通の中間データ表現・文分割)
                                └──────────────────┘

【各クレートの役割サマリー】

1. suffolk-ir (Intermediate Representation)
   - 最下層のコアデータ構造クレート。
   - すべてのファイル形式・入出力フォーマットが共通して扱う「中間表現（DocumentIR）」を定義。
   - 文単位の分割（Segmenter）やタグ抽象化（Placeholders）もここで処理します。

2. suffolk-codec (Data Serializer / Deserializer)
   - 中間表現（IR）と翻訳データ交換形式（XLIFF 1.2 / Shuttle Web Viewer JSON / フェイルセーフ形式）
     との相互変換（エンコード／デコード）を担当します。

3. suffolk-formats (Native Document Parsers)
   - 各種ネイティブ原稿ファイル（DOCX, XLSX, PPTX, HTML, Markdown, TXT, IDML 等）の
     解析・テキスト抽出（Filter/Extract）および翻訳後ファイルの復元（Merge）を担当します。

4. suffolk-cli (Command Line Interface)
   - ユーザーがターミナルから `suffolk filter` や `suffolk merge` を実行するための
     エントリーポイント（実行可能バイナリ）です。上記の3つのクレートを統合して処理を実行します。

5. suffolk-wasm (WebAssembly Bindings for Browser & VS Code)
   - ブラウザアプリケーション（Web / SPA / SheepCombWeb）および VS Code 拡張機能（Node.js / SheepWeave）
     から Suffolk の抽出・マージ・文分割機能をゼロオーバーヘッドかつメモリ上で直接呼び出すための WASM エントリポイントです。

--------------------------------------------------------------------------------

   それぞれのフォルダ内の `readme.txt` をご覧ください。
